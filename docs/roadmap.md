# What we could work on next

We're still choosing the application. These tasks can help us explore a few directions together.

- [ ] Try the demo on another teammate's computer and improve the setup guide.
- [ ] Choose a small project story: who needs help, and what should the robot do?
- [ ] Improve exploration when the location estimate becomes unreliable.
- [ ] Compare camera-only obstacle mapping with the current depth-based setup.
- [ ] Measure latency, memory, and control speed on Jetson Nano.
- [ ] Add perception for the chosen story, such as finding an object or tracking a person.

For an experiment, it helps to pick one question and one comparison. For example, we could compare two exploration strategies using the time needed to observe the same area. The [project proposal template](https://github.com/henry753951/jetbot-navigation/issues/new?template=project-idea.md) gives us a place to start that discussion.
